# AGENTS.md

Vite 8 + React 19 + TypeScript strict + MUI v9 + React Router v7 PWA template. No test framework: verification is `npm run lint` + `npm run build`.

## Commands

- `npm run dev` — dev server; PWA service worker is active in dev (vite-plugin-pwa `devOptions.enabled`), so hard-reload after config/asset changes if the SW serves stale code.
- `npm run build` — `tsc -b` typecheck + production build to `dist/` (no standalone typecheck script).
- `npm run lint` — oxlint (rules: react/oxc plugins).
- `npm run preview` — preview the built app (needed to validate PWA install).
- `npm run generate:pwa` — regenerates `public/pwa-*.png` / `apple-touch-icon` / `maskable` icons from `public/logo.svg`; re-run after changing the logo.

## Architecture rule (containers vs components)

- `src/containers/*` own ALL logic and state (fetch, events, hooks like `useLocalStorage`); they must not contain presentation details.
- `src/components/*` are pure: receive props and callbacks, reusable and swappable (also for a future React Native client).
- State originates in the container and flows down to components. New feature = new folder in `containers/` + matching `components/`, route registered in `src/app/router.tsx` (wildcard redirects to `/404`).

## Import/TS quirks (build fails if violated)

- Relative imports MUST include the file extension: `import App from './app/App.tsx'`.
- Type-only imports must use `import type` (`verbatimModuleSyntax`).
- `erasableSyntaxOnly`: no TS enums, namespaces, or parameter properties.

## PWA / branding gotchas

- Brand color exists in 3 unlinked places: `BRAND_COLOR` in `src/theme/theme.ts`, `theme_color` in the `manifest` const in `vite.config.ts`, and the `theme-color` meta in `index.html`. Update all three.
- PWA manifest (name, description, icons) lives in `vite.config.ts`; matching `name`/`description` meta in `index.html`.
- Reworking the template = update `package.json` name, manifest + `index.html` meta, logo, then `npm run generate:pwa`.
- `dev-dist/` is generated by the PWA plugin in dev but is currently tracked in git; `dist/` is ignored.

## Conventions

- UI strings and code comments are in Italian; keep them that way.
- No state management library — plain React hooks; structure is ready to add Zustand/Redux/TanStack Query if needed.
